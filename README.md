## 📌 Objective
Analyze global product demand and identify high-growth regions to support expansion strategy.

## 📊 Tools Used
- Power BI
- DAX
- Excel

## 🔍 Key Insights
- Strong demand in European regions
- Top 10 countries generate majority revenue
- Customer concentration impacts revenue stability

## 📈 Dashboard Features
- Interactive slicers
- Drill-down analysis
- KPI cards
- Geo-map demand visualization
